## 1. Pendahuluan

Frosthoot Studio ("kami") menghormati privasi Anda. Kebijakan ini menjelaskan data apa yang dikumpulkan oleh aplikasi **Waktu Shalat** ("Aplikasi"), bagaimana kami menggunakannya, dan hak Anda atas data tersebut.

Dengan menggunakan Aplikasi ini, Anda menyetujui praktik yang dijelaskan dalam kebijakan ini.

---

## 2. Data yang Kami Kumpulkan

### 2.1 Data Lokasi
Aplikasi membutuhkan akses lokasi untuk menghitung waktu shalat dan arah kiblat yang akurat. Lokasi Anda **diproses sepenuhnya di perangkat** dan **tidak dikirim ke server kami**. Anda dapat mencabut izin lokasi kapan saja melalui pengaturan perangkat.

### 2.2 Data Penggunaan Anonim (Firebase Analytics)
Kami menggunakan Google Firebase Analytics untuk memahami bagaimana pengguna berinteraksi dengan Aplikasi. Data yang dikumpulkan mencakup:
- Layar yang dibuka
- Fitur yang digunakan (misalnya: surah Al-Quran yang dibuka, dzikir yang diselesaikan)
- Bahasa, metode kalkulasi shalat, dan font Arab yang dipilih
- Versi aplikasi, versi sistem operasi, model perangkat (anonim)

Data ini **tidak mengandung identitas pribadi** dan digunakan hanya untuk meningkatkan kualitas Aplikasi.

### 2.3 Laporan Crash (Firebase Crashlytics)
Jika Aplikasi mengalami crash, kami otomatis menerima laporan teknis (stack trace, model perangkat, versi OS) untuk memperbaiki bug. Laporan ini **tidak mengandung data pribadi atau konten yang Anda baca/dengarkan**.

### 2.4 Iklan (App Open Ad — akan datang)
Saat fitur monetisasi diaktifkan, Aplikasi akan menampilkan **App Open Ad** (iklan saat membuka aplikasi) menggunakan Google AdMob. AdMob dapat mengakses Advertising ID perangkat Anda untuk personalisasi iklan. Anda dapat mereset atau menonaktifkan Advertising ID melalui pengaturan perangkat.

**Catatan:** Aplikasi tidak menampilkan iklan banner, iklan native, iklan interstitial di tengah penggunaan, maupun iklan rewarded.

### 2.5 Pembelian Dalam Aplikasi (akan datang)
Jika Anda membeli versi Premium atau memberikan donasi melalui Aplikasi, transaksi diproses oleh **Google Play Billing**. Kami hanya menerima konfirmasi pembelian (anonim) — tidak menerima nomor kartu kredit atau detail keuangan Anda.

## 3. Bagaimana Kami Menggunakan Data

Kami menggunakan data di atas untuk:
- Menghitung waktu shalat dan arah kiblat

- Memperbaiki bug dan crash
- Menampilkan iklan yang relevan (saat fitur monetisasi aktif)
- Memvalidasi pembelian Premium (saat fitur tersedia)

## 5. Penyimpanan Data Lokal

Aplikasi menyimpan data berikut **hanya di perangkat Anda** (tidak diunggah ke server):
- Riwayat shalat dan dzikir Anda
- Bookmark surah dan ayat
- Pengaturan (bahasa, font, metode kalkulasi)
- Cache teks Al-Quran (untuk akses offline)

Data ini akan terhapus saat Anda meng-uninstall Aplikasi.
